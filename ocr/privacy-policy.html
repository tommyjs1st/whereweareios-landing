OCR번역기 개인정보 처리방침

최종 업데이트: 2025년 1월 8일

OCR번역기는 사용자의 개인정보를 수집하지 않습니다. 모든 번역 기록과 단어장 데이터는 사용자의 기기에만 저장되며, 사용자가 완전히 통제할 수 있습니다.

1. 수집하는 정보

OCR번역기는 다음과 같은 개인정보를 수집하지 않습니다:

  • 이름, 이메일, 전화번호 등의 개인 식별 정보
  • 위치 정보
  • 기기 식별자
  • 사용 통계 또는 분석 데이터
  • 촬영한 사진 원본

2. 데이터 저장 방식

2.1 로컬 저장

다음 데이터는 사용자의 iPhone/iPad 기기에만 저장됩니다:

  • 번역 기록 (원문과 번역문)
  • 단어장 (저장된 단어, 뜻, 예문)
  • 언어 설정

이러한 데이터는 앱을 삭제하면 함께 삭제됩니다.

2.2 백업 및 복원

앱 데이터는 사용자가 직접 내보내기/가져오기 기능을 통해 백업할 수 있습니다. iCloud 백업 설정에 따라 기기 백업에 포함될 수 있습니다.

3. 외부로 전송되는 데이터

3.1 번역 서비스

번역 기능을 제공하기 위해 다음 데이터가 Anthropic Claude API로 전송됩니다:

  • OCR로 인식된 텍스트
  • 사용자가 조회한 단어

중요: 사진 원본은 전송되지 않습니다. 텍스트 인식은 기기 내에서 Apple Vision 프레임워크를 통해 처리되며, 인식된 텍스트만 번역을 위해 전송됩니다.

3.2 Anthropic의 개인정보 처리

Anthropic Claude API는 다음과 같이 데이터를 처리합니다:

  • 전송된 텍스트는 번역 서비스 제공 목적으로만 사용됩니다
  • 개인을 식별할 수 있는 정보는 포함되지 않습니다
  • 자세한 내용은 Anthropic 개인정보 처리방침을 참조하세요

4. 데이터 보안

  • 모든 API 통신은 HTTPS를 통해 암호화됩니다
  • 기기에 저장된 데이터는 iOS의 보안 샌드박스로 보호됩니다
  • 제3자와 데이터를 공유하지 않습니다

5. 사용자의 권리

사용자는 언제든지 다음과 같은 권리를 행사할 수 있습니다:

  • 앱 내에서 저장된 번역 기록 삭제
  • 앱 내에서 저장된 단어장 데이터 삭제
  • 앱 삭제를 통한 모든 데이터 완전 삭제
  • 데이터 내보내기를 통한 백업 생성

6. 아동의 개인정보 보호

OCR번역기는 모든 연령대가 사용할 수 있으며, 아동의 개인정보를 포함한 어떠한 개인정보도 수집하지 않습니다.

7. 개인정보 처리방침의 변경

본 개인정보 처리방침은 필요에 따라 업데이트될 수 있습니다. 중요한 변경사항이 있을 경우 앱 업데이트 공지를 통해 알려드립니다.
