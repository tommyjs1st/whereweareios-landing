앱 소개

OCR번역기는 영어, 일본어, 스페인어를 한글로 번역해주는 iOS 앱입니다. 사진 촬영만으로 텍스트를 인식하고 AI가 자동으로 번역해드립니다.

주요 기능

  • 사진으로 텍스트 인식 (OCR)
  • AI 기반 정확한 번역
  • 단어 터치로 즉시 뜻 확인
  • 자동 단어장 생성
  • 번역 기록 저장 및 관리

자주 묻는 질문

어떤 언어를 지원하나요?

현재 영어, 일본어, 스페인어를 한글로 번역할 수 있습니다. 각 언어는 앱 내에서 선택할 수 있습니다.

인터넷 연결이 필요한가요?

번역 기능을 사용하려면 인터넷 연결이 필요합니다. 하지만 저장된 번역 기록과 단어장은 오프라인에서도 확인할 수 있습니다.

개인정보는 안전한가요?

네, 모든 번역 기록과 단어장은 사용자의 기기에만 저장됩니다. 사진 원본은 외부로 전송되지 않으며, 번역을 위해 텍스트만 암호화되어 전송됩니다. 자세한 내용은 개인정보 처리방침을 참조하세요.

저장된 데이터를 백업할 수 있나요?

네, 앱 내에서 번역 기록과 단어장을 ZIP 파일로 내보내기할 수 있습니다. 내보낸 파일은 다시 가져오기하여 복원할 수 있습니다.

OCR 인식이 잘 안 되는 경우는?

다음 사항을 확인해주세요:

  • 사진이 흐릿하지 않고 선명한지 확인
  • 텍스트가 잘 보이도록 충분한 조명 확보
  • 번역할 영역을 정확하게 선택
  • 인식 후 텍스트 수정 기능 활용

단어장은 어떻게 사용하나요?

번역된 텍스트에서 모르는 단어를 터치하면 뜻과 예문이 표시됩니다. 조회한 단어는 자동으로 단어장에 저장되어 나중에 복습할 수 있습니다.

번역 품질이 만족스럽지 않은 경우는?

OCR 인식 후 텍스트 수정 기능을 사용하여 인식된 텍스트를 수정한 후 재번역할 수 있습니다. 인식이 정확할수록 번역 품질도 향상됩니다.

번역 횟수에 제한이 있나요?

앱은 완전 무료이며, 100,000토큰까지 사용이 제한됩니다.

  • 일반적인 문장 하나는 약 50-100토큰 정도입니다
  • 토큰은 번역과 단어 조회 시 사용됩니다
  • 100,000토큰 사용 후 추가로 사용하시려면 이메일로 요청해주세요
  • 요청하시면 무료로 사용 제한을 해제해드립니다

사용 제한은 어떻게 해제하나요?

100,000토큰을 모두 사용한 경우, 위의 이메일 주소로 연락주시면 무료로 사용 제한을 해제해드립니다. 이메일에 다음 정보를 포함해주세요:

  • 앱에 표시된 기기 ID
  • 사용 제한 해제 요청 내용
확인 후 빠르게 제한을 해제해드리겠습니다. 별도의 비용은 발생하지 않습니다.
